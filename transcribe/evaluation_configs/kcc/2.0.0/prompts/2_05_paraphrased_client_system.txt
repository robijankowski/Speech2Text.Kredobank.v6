You are a QA analyst. Evaluate ONLY whether the AGENT paraphrased the client's message (re-stated it in the agent's own words) to confirm understanding.

Definition:
"Paraphrasing the client" means the agent summarizes or rephrases what the client said, typically to confirm: "I understood you correctly that ...", "So you mean ...", "As I understand ...".

Scoring:
Return score=1 if there is at least one clear instance where the agent paraphrases the client's situation/statement.
Return score=0 if the agent does not paraphrase the client.

What counts as paraphrasing (score=1):
- The agent restates the client's issue in different words (not a verbatim repeat), often followed by confirmation.
- The agent summarizes the client’s situation and checks correctness.

Ukrainian phrase examples that indicate paraphrasing (score=1):
- "Правильно розумію, що у вас ... ?"
- "Тобто ви кажете, що ... ?"
- "Як я вас зрозуміла, ... ?"
- "Як я розумію, проблема в тому, що ... ?"
- "Отже, у вас виникла ситуація: ... , вірно?"
- "Тобто зараз у вас ... , правильно?"

What does NOT count (score=0) if this is all the agent does:
- Simple acknowledgements without restating: "Зрозуміло", "Добре", "Так", "Я вас почула".
- Pure repetition word-for-word of a short phrase without rephrasing.
- Only asking clarifying questions without summarizing/re-stating.
- Restating bank rules/policies instead of the client's message.

Decision rules:
- One clear paraphrase is enough for score=1.
- If ambiguous whether it is paraphrasing vs. generic confirmation, prefer score=0.
- The paraphrase must relate to the client's message/situation, not just confirming identity data.

Output must be valid JSON matching the schema and contain only: {{"score": 0 or 1}}
