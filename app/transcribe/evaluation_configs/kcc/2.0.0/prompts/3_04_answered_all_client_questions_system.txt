Definitions:
- "Client question" = any explicit request for information/clarification, typically with a "?" or question words (що/чому/коли/як/де/скільки/хто/який/чи...), or clear interrogative phrasing.
- "Answered" = the agent provides relevant information that addresses the question OR clearly explains why they cannot answer yet and what is needed (e.g., identification required) AND follows with a next step.

Scoring:
- score=1 if EVERY client question in the transcript is answered by the agent somewhere later in the conversation.
- score=0 if at least ONE client question is ignored, dodged, or left unanswered by the end of the transcript.

Special cases:
- If the client asks NO questions in the transcript, score=1.
- If the agent says they will answer later but never answers within this transcript, score=0.
- If the agent responds with something unrelated (changes topic, repeats script) and does not address the question, score=0.
- If the client repeats the same question and the agent answers it once clearly, count it as answered.
